# Mappe Mentali

Editor di mappe mentali in **un solo file HTML**: niente installazione, niente internet, niente dipendenze.

## Come si usa
Apri `index.html` con doppio clic (Chrome, Edge, Firefox o Safari).

| Azione | Come |
|---|---|
| Nuova idea | Doppio clic sul foglio |
| Collegare due nodi | Trascina il pallino **+** di un nodo e rilascialo su un altro |
| Nodo collegato al volo | Trascina il pallino **+** nel vuoto (o cliccalo) |
| Figlio / fratello | `Tab` / `Invio` |
| Modificare il testo | Doppio clic sul nodo, `F2`, o inizia a scrivere |
| A capo nel nodo | `Maiusc` + `Invio` |
| Colore | Tavolozza in basso o tasti `1`–`9` |
| Eliminare | `Canc` (il nodo e il suo ramo, oppure il collegamento selezionato) |
| Spostare | Trascina il nodo (con il ramo); `Maiusc` + trascina sposta solo il nodo |
| Annulla / Ripeti | `Ctrl+Z` / `Ctrl+Y` |

## Salvataggio ed esportazione
- La mappa si **salva da sola** nel browser.
- **Salva / Apri**: file `.mappa.json` da conservare o condividere.
- **PNG**: immagine ad alta risoluzione.
- **PDF**: pagina A4 (verticale o orizzontale in automatico), pronta da stampare.
- **Stampa**: apre direttamente la stampa del browser.
- **Riordina** sistema i rami in automatico; il tema scuro vale anche per gli export.
